# CLAUDE.md · 전태환의 학습 폴더

## 1. 나는 누구

- 트랙: AX 데이터·서비스 트랙
- 분야: 콘텐츠 / 뷰티 / 푸드 / 리테일 (네 분야 모두)
- 팀: 올리브 유니버스, 팀원 김이지, 전태환, 김혜성
- 전공·경력: 건축공학과 재학, 경력 없음
- 잘하는 것: AI 활용, 창의적인 생각, 콘텐츠 제작, 뛰어난 열정
- 아직 낯선 것: 터미널, 폴더 경로, 데이터 분석, 자료 파악, 주제 선정, 프로젝트 진행 (아직 모든 게 새로움)

## 2. 6주 목표 (어제 쓴 학습목표 초안에서 옮겨 옵니다)

- 6주 뒤 내가 손에 쥘 결과물: 광안리 부산불꽃축제를 공공데이터(축제·상가·데이터랩)와 공식 자료로 분석한 리서치 노트 2장과 발표 자료 1개, 그리고 그 과정의 Before / After 프롬프트 예시 5쌍
- 그걸 위해 이번 주에 할 것: 부산 상가 공공데이터 CSV를 내려받아 `inputs/`에 넣고, `SOURCE.md`에 출처를 적고, `keyword-map.md`에 키워드 12개 채우기

## 3. 선호 작업 방식

- 설명은 쉬운 말로 해 주세요.
- 한 번에 3단계 이상 시키지 말고, 끝날 때마다 확인을 받아 주세요.
- 파일을 만들거나 고치기 전에 무엇을 바꿀지 먼저 말해 주세요.

## 4. 할루시네이션 방지 규칙 (지우지 마세요)

- 숫자·날짜·인명·인용에는 반드시 출처 URL을 붙입니다. URL이 없으면 쓰지 않습니다.
- 직접 열어 확인하지 못한 내용은 `[확인 필요: 무엇]`으로 표시합니다.
- 한 출처에만 있는 주장은 "○○ 보도에 따르면"이라고 출처를 밝혀 씁니다.
- 회사가 밝히지 않은 이유는 사실처럼 쓰지 않고 "가설:"로 씁니다.
- 리서치 결과는 채팅 답으로 끝내지 말고 `research/` 폴더에 노트 파일로 저장합니다.
- 노트에는 확인한 날짜(YYYY-MM-DD)를 적습니다.
- inputs/ 숫자는 파일 값 그대로 쓰고 반올림하지 않는다.
- 두 출처의 숫자가 다르면 둘 다 적고 어느 쪽인지 고르지 않는다.

## 5. 폴더 규칙

- 프롬프트에 폴더 없이 파일 이름만 있으면 맨 위(llm-academy/)에 저장한다.
- 프롬프트가 파일 이름만으로 기존 파일을 읽으라고 하면, 맨 위에 없을 때 `refactor-log.md`를 보고 옮긴 자리에서 찾는다.
- 자산 표는 `assets/`, 데이터 명세는 `specs/`, 리서치 노트는 `research/`, 쓰지 않는 옛 파일은 `archive/`에 둔다.
